GCN Studio

Application de production et publication de contenu vidéo sur TikTok

Qu'est-ce que GCN Studio ?

GCN Studio est une application développée et opérée par Genaro-Cedric Nisus, accessible via le site www.gcn-data.fr. Elle permet de produire du contenu vidéo court à destination de TikTok et de le publier directement sur les comptes du créateur, via l'API officielle TikTok Content Posting, après autorisation explicite (OAuth 2.0).

Fonctionnalités principales

  • Authentification OAuth 2.0 avec un compte TikTok du créateur
  • Affichage du profil et des statistiques publiques (abonnés, likes, vues, vidéos)
  • Consultation de la liste des vidéos publiées et de leurs métriques
  • Publication directe de nouvelles vidéos sur TikTok depuis l'interface GCN Studio
  • Gestion sécurisée des jetons d'authentification (access + refresh tokens)

Intégrations TikTok utilisées

Login Kit Content Posting API user.info.basic user.info.stats video.list video.publish

Architecture

  • Frontend : application web React/Vite, accessible via /admin/tiktok
  • Backend : Node.js / Express hébergé sur Fly.io
  • Stockage : MongoDB (tokens chiffrés, métriques agrégées)
  • Communication TikTok : API officielle uniquement, via les endpoints documentés
